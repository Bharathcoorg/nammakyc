# Contributing

Thank you for contributing to Namma KYC.

## Development principles

- Keep changes focused and understandable.
- Add or update tests with behavior changes.
- Do not add real citizen, Aadhaar, biometric, OTP, credential, or production integration data.
- Do not use undocumented government endpoints.
- Keep provider integrations behind the defined interfaces.
- Use clear Conventional Commit messages for meaningful changes.
- Public commits must describe the engineering change, not internal planning or development discussions.
