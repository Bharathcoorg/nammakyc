# Government visual references

The interactive demo and Android splash use the following external visual references so the government-facing artwork is not recreated as an invented illustration:

- **Karnataka state emblem:** Wikimedia Commons, *Seal of Karnataka.png* (raster variant of the documented state emblem). The Commons page identifies it as the official Emblem of Government of Karnataka and notes that use of official insignia may be restricted independently of copyright. The Android splash uses the PNG variant because React Native's standard image component expects a raster asset here. See the source page before any production/public-service deployment.
- **Vidhana Soudha:** Wikimedia Commons, *Government Karnataka 8352.jpg*, an actual photograph of Vidhana Soudha in Bengaluru. The Commons page identifies the author/license information for that photograph.

These assets are used here as visual references for an independent open-source concept. Namma KYC is not presented as an official Government of Karnataka application.

The UI keeps the Namma KYC product mark separate from the Karnataka government emblem. English and Kannada are rendered as separate complete language experiences; the splash language control only switches the experience.
